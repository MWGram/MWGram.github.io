MimbleWimbleGram (MWGRAM)

A privacy-focused open source P2P communication and currency protocol.

Vision

We will build a private, peer-to-peer messaging system that minimizes metadata and resists censorship. No phone numbers. No email. No central authority. End-to-end encryption by default. Users keep custody of their keys and coins. Predictable monetary policy. Intentional scarcity.

Roadmap (High Level)

  • Fork and configure core blockchain parameters
  • Build node and wallet infrastructure
  • Implement lottery-based and multi-algorithm mining
  • Reinforce 51% attack resistance
  • Enable on-chain messaging and TTL-based expiry
  • Integrate wallet chat system
  • Launch public testnet, audit, gather feedback
  • Transition to mainnet and community adoption

Burn & Scarcity

A transparent burn mechanism will gradually reduce circulating supply. Each burn is verifiable on the Polygon blockchain. The aim is to mirror Bitcoin’s DNA — predictable issuance, deliberate scarcity — with improved resilience.

Future Blockchain & Token Migration

MWGRAM is currently a Polygon token. We are building a dedicated blockchain for private, censorship-resistant communication and transactions.

When the MWGRAM blockchain launches, every Polygon token holder will receive 1 native coin per token (1:1 migration).
